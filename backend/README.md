# Employee Attendance Management System - Backend API

Express REST API built with Node.js, JWT, bcrypt, and PostgreSQL.

## Environment File Setup (.env)
```env
PORT=5000
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/attendance_db
JWT_SECRET=supersecretjwtkey123_interview_project
NODE_ENV=development
```

## Setup & Seed
```bash
npm install
npm run seed
npm run dev
```
